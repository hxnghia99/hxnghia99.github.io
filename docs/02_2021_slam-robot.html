Mobile Robot with 3D SLAM & Deep Learning

Undergraduate Thesis Project · 2020 – 2021 · Ho Chi Minh City, Vietnam

Architecture

A three-wheel mobile robot (designed in SolidWorks) running ROS1 on Ubuntu, using RTABMAP for 3D SLAM with an RPLidar and RealSense D435i camera. Localization via AMCL, path planning via Dijkstra's algorithm, and obstacle avoidance via the Dynamic Window approach.

A Wi-Fi client-server link integrates a deep-learning-based human-tracking model with the SLAM stack for combined detection and tracking.

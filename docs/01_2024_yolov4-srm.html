YOLOv4-SRm: Super-Resolution for Small Object Detection

First Author · 2022.03 – 2024.01 · Seoul, South Korea

Architecture

A lightweight Super-Resolution module (SRm) inserted into the YOLOv4 backbone, upsampling low-resolution feature maps before detection to recover fine-grained detail for small objects in surveillance and drone imagery.

A simplified variant (SSRm) reduces parameter count and FLOPs further, then goes through pruning and INT8 quantization for deployment via the Qualcomm® Neural Processing SDK (SNPE) on a Qualcomm QCS610 SoC.

Performance

+11.38% AP50 on the company surveillance dataset and +6.29% AP50 on VisDrone2019, compared to vanilla YOLOv4, with fewer parameters.

The pruned and quantized SSRm variant runs at 36 FPS on-device, enabling a real-time CCTV detection framework.
